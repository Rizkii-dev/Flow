# Flow

**Flow** is an Android application designed to assist children with word blindness (dyslexia) in improving their reading and literacy skills. The application provides interactive features and visual aids structured to make reading more accessible, engaging, and effective for young learners.

---

## 🚀 Features

* **Dyslexia-Friendly Text & Layouts:** Uses clear, legible typography and customizable visual spacing to ease word recognition.
* **Interactive Reading Assistance:** Features tailored to help children break down words, recognize characters, and improve reading comprehension.
* **Privacy-Focused:** Built with user privacy in mind. Includes a dedicated Privacy Policy within the repository.

---

## 🛠 Tech Stack & Architecture

* **Platform:** Android
* **Language:** Kotlin / Java
* **Build System:** Gradle
* **IDE:** Android Studio
